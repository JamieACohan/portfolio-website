# Portfolio Website

Personal portfolio website for Jamie Cohan - Software Engineer.

## Tech Stack

- **HTML5** – Semantic structure
- **CSS3** – Custom styling (Flexbox, Grid, CSS Variables)
- **Vanilla JS** – Mobile navigation, scroll animations

## Features

- Modern dark theme with purple accent
- Responsive mobile-first design
- Smooth scroll navigation
- Fade-in animations on scroll
- Glassmorphism card effects

## Sections

- Hero
- About
- Skills
- Experience
- Projects
- Contact

## Usage

Just open `index.html` in your browser. No build step required.

## Deployment

Push to GitHub and enable GitHub Pages pointing to the root directory.
